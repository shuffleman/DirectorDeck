# 交付前质检清单（DirectorDeck 剧本工坊）

按顺序过；任何一项不过都先修再交付。优先修“会直接导致导入失败/生成失败”的问题，
最后才修文采。

## 一、前置锁

- [ ] 用户确认了交付目标是 **DirectorDeck**（不是 Seedance/图N 投喂）；
- [ ] 总时长、段数、每段秒数确定（默认 5 秒，≤64 段）；
- [ ] 画幅/分辨率确定（16:9 / 9:16 / 1:1；480p/720p/768p/1080p）；
- [ ] 语言、类型、文风确定；
- [ ] 哪些台词/事件/结局必须保留已记录；
- [ ] 素材槽/参考图是否可用已确认。

## 二、故事与结构

- [ ] 一句话能说清主角、欲望、阻力、代价；
- [ ] 每段只解决一个主要事件；
- [ ] 第 1 段前 3 秒有钩子；
- [ ] 每 2–3 段有一次升级/反转；
- [ ] 结尾有结果或悬念，不是硬切；
- [ ] 没有为凑段数加入的纯 filler；
- [ ] 下一段开头能接上一段结尾（状态/位置/动作/情绪）。

## 三、人物与设定

- [ ] 角色名全篇一致，≤12 字符，不含冒号/空格；
- [ ] 每个主要角色有明确欲望/阻力；
- [ ] 配角没有抢主线；
- [ ] 外形/服装/标志物/伤口全篇一致；
- [ ] 人物关系与称呼一致；
- [ ] 没有凭空新增关键身份/能力/关系/结局。

## 四、台词

- [ ] 3 秒 ≤9 字，5 秒 ≤16 字，10 秒 ≤30 字（中文）；
- [ ] 台词是口语，不是书面语/解释文；
- [ ] 没有在台词里写动作、神态、镜头说明；
- [ ] 一段最多一个主要说话人；
- [ ] 连续纯对白不超过 2 段；
- [ ] 台词符合角色身份/性格/当下情绪；
- [ ] 关键台词没有被删或改意思（用户要求保留时）。

## 五、画面、镜头与连续性

- [ ] 每段有一个视觉变化（走位/景别/动作/光线）；
- [ ] 每段只安排一个主要运镜；
- [ ] 动作可拍：谁、什么状态、做什么、结果、停在哪；
- [ ] 没有一段里堆 3 个以上动作节拍（打戏 2–3 拍）；
- [ ] 轴线/站位/出入口一致；
- [ ] 时间/天气/光线/服装/道具位置连续；
- [ ] 不依赖观众看不到的信息。

## 六、素材与声音

- [ ] `@图片N` 全部在 1..9；
- [ ] 每个槽是用户确认过的；没有猜编号；
- [ ] 同一角色全篇同一槽；不同身份不复用同一图；
- [ ] 没图/没槽时没有写 `@图片N`；
- [ ] 角色名与 TTSBooth/VoiceLock 的 CAST 一致；
- [ ] 音频槽和图片槽没有混用编号；
- [ ] 需要锁音时，台词长度给 TTS 留了自然停顿。

## 七、格式与导入

- [ ] 段头 `第N段（X秒）`，N 从 1 连续，秒数 1–60；
- [ ] 段数 ≤64；
- [ ] 对白行符合 `角色：台词`；
- [ ] 动作行开头没有 `角色：`；
- [ ] 没有 Markdown 代码围栏；
- [ ] 没有分析、创作说明、自检表混进正文；
- [ ] JSON 没有注释/尾逗号，字段名正确；
- [ ] V6 段头/`<d>`/`<Picture N>` 符合契约；
- [ ] 已跑校验器且无 error。

校验器：

```bash
python skills/directordeck-screenplay-studio/scripts/validate_screenplay.py 剧本.txt --format auto
```

## 八、交付说明

- [ ] 已说明格式（DD 文本/JSON/V6）；
- [ ] 已说明段数/总时长/画幅；
- [ ] 已附“角色 → 素材槽 → 音色”对照表（如有）；
- [ ] 已说明为适配段长做过的压缩/拆分；
- [ ] 已给出画布接法（M13/M16）或下一步操作。

## 九、返工优先级

1. 导入失败/格式错误；
2. 素材槽越界/空槽；
3. 连续性与人物设定矛盾；
4. 一段多事件/台词超长；
5. 镜头与文采。

## 十、常见错误速查

| 错误 | 后果 | 修法 |
|---|---|---|
| 段号跳号/重复 | 导入器段落错位 | 重编号为 1..N 连续 |
| 秒数 0 或 >60 | 导入/生成报错 | 调到 1–60 |
| 段数 >64 | 导入截断 | 拆文件/删 filler |
| 动作行写 `女主：转身` | 被当对白 | 改成 `女主转身` 或放 `[画面]` |
| 5 秒写 25 字台词 | TTS 念不完/口型对不上 | 砍到 16 字内或拆段 |
| `@图片10` | `DD-E010` | 改到 1..9 |
| 引用空槽 | `DD-E011` | 补图或不写 refs |
| 混入 `图N` | Seedance/DirectorDeck 编号混乱 | DirectorDeck 稿只用 `@图片N` |
| 代码围栏 | 导入器把 ``` 当正文 | 去掉围栏 |
| 连续 3 段纯对白 | 画面死、节奏塌 | 加动作/空间变化或并段 |
| 上段门外下段屋内无过渡 | 观众跳戏 | 补过渡动作/镜头 |
| 同角色换图 | 人物不一致 | 固定角色→槽位 |
