# DirectorDeck 外部剧本格式（导入契约）

本文件只描述 `DirectorDeck_ScriptImport` 能吃进去的三种格式。**以本文件为准**；
创作内容仍由其他 skill / 用户决定。

导入节点参数：

| 参数 | 说明 |
|---|---|
| `script` | 粘贴下面任意一种文本 |
| `format` | `自动识别` / `DirectorDeck 剧本` / `JSON 剧本` / `H3 V6 文本` |
| `segment_seconds` | 文本没写秒数时的默认段长（默认 5.0） |
| `match_assets` | 是否自动匹配素材库图片槽 |
| `match_scenes` | 是否把段落场景关键词匹配到场景槽 |
| `min_score` | 匹配阈值（默认 0.55） |

自动识别顺序：JSON（以 `{` 开头或含 `"segments"`）→ H3 V6（有 `【第N段` 段头）→
DirectorDeck 文本。解析失败会报 `DD-E061`。

---

## 1. DirectorDeck 文本（默认推荐）

```text
第1段（5秒）
[画面] 雨夜，女主撑着伞站在老宅台阶下，男主从门内走出 @图片1
女主：你终于回来了。
男主：这十年，我一直在找你。

第2段（5秒）
[画面] 两人在雨中对视，镜头缓慢推近女主的脸 @图片1 @图片2
女主：先进屋吧。
```

规则：

- 段头：`第N段（X秒）`；也接受“第N幕/第N镜/第N场”，但导入稿统一写“段”；
- N 从 1 开始连续编号；秒数 1–60，可用小数（如 `5.5秒`）；
- 段与段之间空行；
- 对白行：`角色：台词`，角色名 1–12 个字符，不能含空格/冒号/引号；
- 动作/运镜：独立一行，推荐以 `[画面]` 开头；
- **动作行开头不要出现“角色名：”**，否则会被解析成对白；
- 素材引用：正文任意位置写 `@图片N`（N=1..9）；会收进该段 refs；
- 导入器会从段头解析时长；标题里没写秒数时用节点默认段长；
- 单文件最多 64 段；超过请拆文件；
- 不要输出 Markdown 代码围栏，不要把创作说明混进正文。

### 台词长度参考

| 段长 | 建议台词 |
|---|---|
| 3 秒 | ≤ 9 个中文字符 |
| 5 秒 | ≤ 16 个中文字符 |
| 10 秒 | ≤ 30 个中文字符 |

放不下时拆句/拆段，不要删剧情。

## 2. JSON 剧本

最小结构：

```json
{
  "title": "雨夜重逢",
  "language": "中文",
  "characters": [
    {"id": "S1", "name": "女主", "image_slot": 1, "audio_slot": 1, "voice": "清冷年轻女声"},
    {"id": "S2", "name": "男主", "image_slot": 2, "audio_slot": 2, "voice": "低沉疲惫男声"}
  ],
  "segments": [
    {
      "index": 1,
      "seconds": 5.0,
      "scene": "老宅台阶，雨夜",
      "actions": "女主撑伞站在台阶下，男主从门内走出",
      "image_refs": [1, 2],
      "dialogue": [
        {"character": "女主", "text": "你终于回来了。", "at": 0.6},
        {"character": "男主", "text": "这十年，我一直在找你。", "at": 2.4}
      ]
    }
  ]
}
```

字段说明（导入器会容错，但交付稿按这个写）：

| 字段 | 必填 | 说明 |
|---|---|---|
| `characters[].name` | 建议 | 角色名；`id` 用于台词引用 |
| `characters[].image_slot` | 可选 | 1–9；不填则交给自动匹配 |
| `characters[].audio_slot` | 可选 | 1–9；锁音时用 |
| `characters[].voice` | 可选 | 音色描述，给 TTS/CAST 用 |
| `segments[].seconds` | 建议 | 1–60，缺省用默认段长 |
| `segments[].scene` | 可选 | 场景/地点 |
| `segments[].actions` | 建议 | 画面、动作、运镜 |
| `segments[].image_refs` | 可选 | 1–9 的图片槽数组 |
| `segments[].dialogue` | 可选 | `{character, text, at?}`；`at` 是段内起始秒 |

不要输出 JSON 注释、尾逗号、Markdown 代码围栏。
一段至少要有画面或台词；段数 ≤ 64。

## 3. H3 V6 文本

```text
【第1段｜5秒】
integrated_multimodal_description: 雨夜，女主撑着伞站在老宅台阶下，男主从门内走出。
(S1) 女主抬头看向他 <d>[克制] 你终于回来了。</d>
(S2) 男主停在门口 <d>这十年，我一直在找你。</d>
<Picture 1> <Picture 2>

【第2段｜5秒】
两人在雨中对视，镜头缓慢推近女主的脸。
(S1) <d>先进屋吧。</d>
<Picture 1>
```

规则：

- 段头固定：`【第N段｜X秒】`（竖线全角/半角都可以，秒数可为小数）；
- 对白：`(S1) 描述 <d>台词</d>`；`S1` 会被当角色名；
- `<d>` 内可带 `[情绪]` 标签，导入器会去掉标签只留台词；
- 图片引用：`<Picture N>`（N=1..9）；
- `integrated_multimodal_description` / `overall_soundscape` / `non_diegetic_music`
  这类行会作为画面描述保留（前缀会被去掉）；
- 段头缺失会直接报错；
- 不要求每段都有台词。

## 4. 三种格式怎么选

| 场景 | 推荐 |
|---|---|
| 直接给 ComfyUI 画布粘贴 | DirectorDeck 文本 |
| 后续还要程序处理/交换 | JSON |
| 用户明确在写 H3 V6 提示词 | H3 V6 |
| 既有人类可读版又有导入要求 | 先交付导入稿；人类可读版另附并标注 |

## 5. 素材槽与自动匹配

- 槽位固定 1..9，`@图片N` 直接对应素材库第 N 槽；
- 素材库为空或没接时，`@图片N` 会触发 `DD-E011`（引用空槽）；
- 不想手动绑定时可以完全不写 `@图片N`，让导入器按角色/场景名自动匹配；
- 要手动绑定，就全篇固定：同一角色始终用同一槽；
- 不要猜槽号，不要给两个身份角色复用同一张图；
- 音频槽只用于锁音/TTS，不要和图片槽混用编号。

## 6. 最小快速模板

```text
第1段（5秒）
[画面] 场景 + 人物状态 + 主要动作 + 运镜，结尾停在可衔接状态
角色：短台词。

第2段（5秒）
[画面] 承接上一段结尾状态，发生下一个事件
角色：短台词。
```
