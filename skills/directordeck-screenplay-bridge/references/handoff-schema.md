# 交接包：创作 skill → DirectorDeck 交付桥

其他创作 skill 在把剧本交给本 skill 前，最好把下面这些信息一次给全。
缺的可以用默认值，但**已定的内容必须标成“锁定”**，本 skill 不会改。

## 一、交付参数

| 字段 | 示例 | 缺省 |
|---|---|---|
| 目标格式 | `DirectorDeck 文本` / `JSON` / `H3 V6` | DirectorDeck 文本 |
| 总时长 | `30 秒` | 按段数 × 段长 |
| 每段秒数 | `5` | 5 |
| 最大段数 | `12` | 64 |
| 语言 | `中文` | 中文 |
| 素材槽 | `@图片1=女主脸，@图片2=男主脸` | 不写 refs，交给自动匹配 |
| 锁音/CAST | `有，角色→音频槽` | 不锁音 |
| 交付方式 | 直接输出 / 存文件（给路径） | 直接输出 |

## 二、创作设定（锁定项）

```yaml
locked:
  title: "雨夜重逢"
  genre: "都市情感"
  characters:
    - name: "女主"
      identity: "…"
      image_slot: 1
    - name: "男主"
      identity: "…"
      image_slot: 2
  ending: "两人进屋，门关上"
  style: "克制、短句、冷色调"
```

`locked` 里的内容本 skill 一律不改；如果格式装不下，只拆段/拆句，不改含义。

## 三、分场/节拍（可调结构）

```yaml
beats:
  - event: "女主在雨夜等男主"
    emotion: "压抑的期待"
    hook: "门内脚步声"
  - event: "男主出现"
    emotion: "克制"
    hook: "两人对视"
  - event: "进屋"
    emotion: "松动"
    hook: "门关上"
```

本 skill 只负责把 beats 切成段；如果用户给了逐段台词，按台词长度拆句/拆段。

## 四、已有的台词（可选）

```yaml
dialogue:
  - speaker: "女主"
    text: "你终于回来了。"
    after_beat: 2
```

台词是创作内容，本 skill 只做长度/格式处理，不重写意思；
确实需要压缩时，保留关键词和语气，并注明“为适配段长做了压缩”。

## 五、素材与声音（可选）

```yaml
assets:
  images:
    "1": "女主脸"
    "2": "男主脸"
    "3": "老宅门廊（场景）"
  audio_slots: {}
cast: {}
```

- 只允许使用这里列出的图片/音频槽；
- 没列出的槽不要写 `@图片N`；
- 如果 `match_assets=true`，也可以完全省略 `@图片N`，让导入器按名字匹配。

## 六、交接回执（本 skill 输出给主 agent）

交付时附一句最小回执（不要写进剧本正文）：

```text
[DirectorDeck 交付] 格式=DirectorDeck 文本；段数=4；总时长=20s；
素材槽=@图片1/@图片2；已压缩台词=1 句；未改剧情/角色/结局。
```

这样下一个 skill 或用户知道格式层做了什么、没做什么，避免互相覆盖。
